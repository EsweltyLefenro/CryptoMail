# CryptoMail

Приложение для защищённой передачи файлов по электронной почте.

**CryptoMail** — desktop-программа на **C# / .NET / WPF**, предназначенная для отправки и приёма файлов с использованием **электронной цифровой подписи** и **шифрования**. Программа позволяет на стороне отправителя выбрать файл, подписать его, зашифровать и отправить по e-mail, а на стороне получателя — принять вложение, расшифровать его и проверить корректность подписи.

Проект разработан как учебная работа по тематике криптографической защиты информации и демонстрирует практическую реализацию защищённого обмена данными между двумя пользователями.

* * *

## Использованные технологии

- **C# / .NET / WPF**
- **MVVM**
- **MailKit**
- **RSA**
- **AES-GCM**
- **SMTP / IMAP**

* * *

## Возможности программы

- генерация пар ключей для отправителя и получателя;
- формирование электронной подписи файла;
- шифрование данных перед отправкой;
- отправка защищённого пакета по электронной почте;
- приём вложения из почтового ящика;
- расшифровка содержимого;
- проверка электронной подписи;
- вывод основных этапов работы в журнале событий интерфейса.

* * *

## Как работает программа

На стороне отправителя исходный файл подписывается с помощью закрытого ключа, после чего упаковывается и шифруется. Далее сформированный защищённый пакет отправляется по электронной почте как вложение.

На стороне получателя программа подключается к почтовому ящику, получает письмо с вложением, выполняет расшифровку пакета и проверяет подпись. После успешной проверки исходный файл сохраняется локально.

* * *

## Назначение проекта

Проект предназначен для демонстрации базовых принципов защищённого обмена данными:

- **конфиденциальности** — за счёт шифрования;
- **целостности** — за счёт проверки подписи;
- **подтверждения подлинности** отправителя — в рамках реализованной схемы обмена ключами.

Программа может использоваться как учебный проект, лабораторная работа или пример практического применения криптографических алгоритмов в desktop-приложении.
