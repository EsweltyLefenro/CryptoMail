# CryptoMail v3.1 - Защищенный обмен файлами

Финальная версия приложения для обмена зашифрованными файлами с использованием RSA и AES-GCM.

## Основные возможности и исправления:

1.  **Исправленный интерфейс:** Цвета кнопок при наведении теперь корректны. Добавлен современный стиль и улучшена читаемость.
2.  **Просмотр пароля:** Добавлена возможность временно увидеть введенный пароль приложения (иконка глаза) для проверки корректности ввода.
3.  **Доверенные ключи:** На вкладке "КЛЮЧИ" реализована возможность добавить публичный ключ отправителя. Это позволяет подтверждать личность отправителя при проверке цифровой подписи.
4.  **Управление журналом:** Добавлена кнопка "Очистить" для быстрого удаления записей из лога событий.
5.  **Хранение данных:** Все ключи, настройки и результаты расшифровки сохраняются в профиле пользователя `%APPDATA%\CryptoMail`. Это гарантирует отсутствие проблем с правами доступа.
6.  **Стабильность:** Исправлены ошибки биндинга кнопок и логика расшифровки пакетов.

## Инструкция:

1.  **Ключи:** На вкладке **"КЛЮЧИ"** сгенерируйте свои пары ключей. Если у вас есть публичный ключ партнера, добавьте его в раздел "Доверенные ключи".
2.  **Отправка:** Укажите данные почты и файл. Приложение подпишет файл вашим приватным ключом и зашифрует его для получателя.
3.  **Получение:** Нажмите "ПОЛУЧИТЬ И РАСШИФРОВАТЬ". Приложение скачает вложение, расшифрует его и проверит подпись, сравнив отпечаток ключа с доверенным (если он добавлен).

## Пути хранения:
- **Ключи:** `%APPDATA%\CryptoMail\Keys`
- **Результаты:** `%APPDATA%\CryptoMail\Output`
- **Доверенные ключи:** `%APPDATA%\CryptoMail\TrustedSenders`

Для быстрого доступа используйте кнопки открытия папок на вкладке "КЛЮЧИ".
